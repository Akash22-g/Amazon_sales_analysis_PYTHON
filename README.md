# Amazon_sales_analysis_PYTHON
Python-based exploratory data analysis of Amazon sales data using Pandas, Matplotlib, and Seaborn to uncover business insights.
# 📊 Amazon Sales Report Analysis

## About the Project

This project focuses on analyzing Amazon sales data using Python. The goal was to clean the dataset, explore sales patterns, and create visualizations that help understand customer purchasing behavior and product performance.

Through this analysis, I practiced data cleaning, exploratory data analysis (EDA), and data visualization using popular Python libraries.

---

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## Project Workflow

- Imported and explored the dataset
- Cleaned missing and inconsistent values
- Performed exploratory data analysis (EDA)
- Created visualizations to identify trends
- Summarized key business insights

---

## Key Insights

- Analyzed sales distribution across different product sizes.
- Identified patterns in customer purchases.
- Used grouping and aggregation techniques to compare sales.
- Visualized important trends using charts and graphs.
